# SimulaOrdem — Design System

Source of truth: `design.json`. Style direction: **Finpay-like SaaS** (teal, white, professional).

## Quick tokens (Tailwind)

| Token | Value | Use |
|-------|-------|-----|
| `brand-600` | `#1C3F3A` | Primary buttons, active nav |
| `brand-500` | `#2A606B` | Hover, links |
| `brand-400` | `#3C8F92` | Accents, charts |
| `surface-900` | `#F8FAFB` | Page background |
| `surface-800` | `#FFFFFF` | Cards |
| `surface-700` | `#F1F5F9` | Inputs, chips |
| `ink` | `#0F172A` | Headings |
| `muted` | `#64748B` | Secondary text |

## Rules

- **No purple.** Ever.
- Cards: white + `border-slate-200` + soft shadow
- Featured blocks: `bg-brand-600` with white text
- Radius: 12px buttons, 16px cards, 24px hero/CTA
- Font: Plus Jakarta Sans

## Logo

Mark = two tilted teal bars + balance dot. Wordmark = Simula (ink) + Ordem (teal).
